# Audio master list

Last updated: 2026-11-11

## In the game

| File | Plays when | Status | Source and licence |
|---|---|---|---|
| `ui/audio/bg.ogg` | Background music, from the main menu on into the game | Done | Team's own |
| `game/solar_system/fuel.ogg` | The fuel pump, for as long as fuel flows | Done | Team's own |
| `game/bus/flying.ogg` | The bus flies: fades in over 0.5 s, loops in step with the music (it is 4 beats long, and starts where the music is in its bar) and fades out over 0.5 s when the flight ends. No pitch or speed change | Done | Team's own |
| `game/bus/dock_bell.ogg` | The bus docks | Placeholder, "to be replaced with the final dock sound" (`game/bus/CREDITS.md`) | Pixabay, Pixabay Content License |
| `game/bus/key_click.ogg` | A bus key goes down | Placeholder | Kenney `click_004`, CC0 |
| `game/passengers/wilhelm_scream.ogg` | A kicked passenger flies out of the bus | Placeholder | Unknown; the licence has to be checked before release (`game/passengers/CREDITS.md`) |
| `ui/audio/ui_click.ogg` | The SFX volume slider moves in Settings. No other button plays it | Placeholder | Kenney `click_001`, CC0 |
| `ui/audio/menu_music.ogg` | Nothing | Unused | Not listed in `ui/audio/CREDITS.md` |

## Named in the specs but not in the game

Nothing. `DESIGN.md`, `docs/ui.md`, `docs/web-constraints.md` and the open issues ask for no sound beyond the four above: the dock bell, the bus key click, the Wilhelm scream and the music starting on the web title card's click. Every other sound is silent, and no doc says it should have one.
